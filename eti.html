[ OVERVIEW ]

Brand Asset Design

I designed print assets for the inaugural Eat The Invaders culinary event, including guest postcards and table cards for 16+ stations. Around 250 guests attended. Each piece followed the same brand system, so the event felt consistent from table to table.

[ MISSION ]

How can I create cohesive graphics for a culinary event across various products [labels, cards, signage] ?

[ EVENT ]

[ TAKEAWAYS ]

Differences in digital to physical print

This project taught me how design moves from screen to paper. I learned to set up files for print, choose the right paper stock, and check proofs before a full run. I also learned how much type size and spacing change once a piece sits on a table instead of a screen. A postcard held in someone's hand needs different scale than the same design viewed at arm's length.
